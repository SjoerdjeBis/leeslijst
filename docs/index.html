Vernieuwen vanaf deze site

De vernieuwknop start een controle op GitHub. Daarvoor heeft deze browser eenmalig een token nodig dat alleen deze repo mag vernieuwen. Het token blijft in deze browser.

  1. Maak een fine-grained token aan.
  2. Kies bij Repository access alleen deze repo.
  3. Zet bij Permissions Actions op Read and write.
